# V12 — Pilot Tracking under Time-Varying Doppler Channels

V12 adds a temporal channel-tracking experiment for Rayleigh/Rician channels generated by the V11 Doppler model.

## New functions

- `src/estimation/temporal_channel_tracker_setup.m` — precomputes causal Jakes-LMMSE weights and posterior error variance.
- `src/estimation/temporal_channel_tracking_apply.m` — applies hold-last, linear interpolation/extrapolation, or causal Jakes-LMMSE tracking.
- `examples/pilot_tracking_validation_run.m` — paired Monte-Carlo pilot-tracking study.
- `src/plots/plot_pilot_tracking_validation.m` — NMSE versus Doppler and pilot update period plots.

## Run

```matlab
run_tests
addpath('examples');
results = pilot_tracking_validation_run;
```

The experiment exports `pilot_tracking_validation.csv`, `.mat`, and plots to `pilot_tracking_results/`.

See `PILOT_TRACKING_MODEL.md` for equations, assumptions and limitations.
