# Final Release Notes - V15.3

The implemented project release is V15.3. The main feature set and regression suite are complete. The owner ran the V15.3 test suite successfully and supplied a 30-frame-per-condition MATLAB validation summary.

The 30-frame run is treated as a confirmation run, not a publication-grade Monte Carlo study. Aggregate CRC-goodput gains over the best retained reference were 13.8% in Rayleigh and 18.9% in Rician. The PER-target feasibility ratios remained 7.3% and 30.5%, so no universal PER guarantee is claimed.

The release includes source, test suite, examples, model docs, final technical report (DOCX/PDF), result CSVs transcribed from the supplied console output, figures, interview brief and CV project descriptions. Raw per-frame result files were not supplied.
