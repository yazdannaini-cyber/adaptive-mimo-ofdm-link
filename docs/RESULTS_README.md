# Curated V15.3 Results

The CSV files in `results/v15_3_final_summary/` were transcribed from the user's MATLAB console output for the 30-frame-per-condition run. They are aggregate tables, not per-frame raw logs.

- `v15_3_30frame_aggregate_results.csv`: all 14 channel / strategy / coding aggregate combinations.
- `v15_3_30frame_adaptive_by_snr.csv`: joint-controller mode, modulation and FEC ratios by channel and SNR.
- `v15_3_run_stability_10_vs_30_frames.csv`: joint CRC-goodput values from 10-frame and 30-frame confirmation runs.

See `DATA_PROVENANCE.md` for details and limitations.
