# CV / Portfolio Description

## English - concise CV bullet

**Adaptive 2x2 MIMO-OFDM Link Simulation | MATLAB**  
Developed an end-to-end pilot-mapped 2x2 MIMO-OFDM simulator with Rayleigh/Rician fading, Doppler, spatial correlation, LS/LMMSE channel estimation, Jakes-LMMSE tracking, Spatial Multiplexing and Alamouti STBC detection. Implemented soft-decision convolutional FEC, Viterbi decoding, CRC-16 and a causal per-burst controller jointly adapting MIMO mode, QPSK/16-QAM and coding rate. In a 30-frame-per-condition validation across 36 channel conditions, the joint controller improved aggregate CRC-accepted goodput by 13.8% (Rayleigh) and 18.9% (Rician) over the best retained reference; PER-target feasibility remained condition-dependent and was explicitly reported.

## English - interview/portfolio paragraph

Built a MATLAB communications simulation platform covering waveform-level 2x2 MIMO-OFDM, pilot-based channel estimation and tracking, time-varying multipath fading, spatial correlation, MIMO equalization, Alamouti diversity, soft-output QAM demapping, convolutional FEC and CRC feedback. The final joint controller selects spatial mode, modulation order and FEC per data burst using causal link estimates and prior ACK/NACK history. The 30-frame validation showed higher aggregate CRC-accepted goodput than the retained adaptive/fixed references in both Rayleigh and Rician channels, while also documenting worst-condition uncertainty and cases where the configured PER target could not be certified.
