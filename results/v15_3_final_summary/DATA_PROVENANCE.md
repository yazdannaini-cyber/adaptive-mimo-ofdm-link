# V15.3 Result Data Provenance

These CSV files contain aggregate values transcribed from the MATLAB console output supplied by the project owner in this conversation. The per-frame MATLAB result files were not uploaded, so the CSV files are curated aggregate summaries, not raw simulation logs. Values retain the precision printed in the console.

The final confirmation run used 30 frames per condition across 36 conditions (Rayleigh/Rician, IID/joint-high spatial profiles, 0/120/300 Hz Doppler, and 8/14/20 dB pilot/data SNR). The console reported 252 summary rows, 7,560 frame-log rows, 3,240 joint burst decisions and 3,240 reference burst records.

The MATLAB test runner was reported by the user to complete successfully; the project test source contains 160 assertions. A full 300-frame default V15.3 run was not supplied. MATLAB release/version was not recorded in the supplied console output.
