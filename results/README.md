# Results directory

New-version simulation output is written here by `run_project`. The two files prefixed `baseline_` are the original CSV files supplied for review; they are preserved for comparison and are not generated by the updated code. Do not overwrite or combine baseline and updated outputs when preparing final plots or reports.


The V12 temporal pilot-tracking runner writes its generated CSV/MAT and plots to the project-level `pilot_tracking_results/` folder.
